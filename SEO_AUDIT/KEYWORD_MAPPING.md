Create a new URL only when it has a distinct search job, unique evidence, and enough original content. Otherwise improve the closest existing page.

## Cannibalization controls

- Give each page one primary intent.
- Do not create separate pages by swapping platform names into identical copy.
- Link from guides to the relevant product page, not every product page.
- Use unique examples, prompts, FAQs, and output demonstrations per page.
- Review Search Console query overlap before merging or splitting pages.
