How to make an animated mystery short

Use one clue, one question, and one reveal. Show the clock that stops, shadow that moves, or book that changes places.

A useful short starts with a clear purpose. These steps will help you shape an idea for your audience and review it before sharing.

Open with an anomaly

Show the clock that stops, shadow that moves, or book that changes places.

Give the question a direction

Make possible explanations distinct enough for a theory.

Place fair clues

Let the audience see details that make the ending plausible.

Reveal with an action

Show the answer through what a character or object does.

Review the promise

Make sure the ending answers the opening question and matches the tone.
