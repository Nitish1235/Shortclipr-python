How to write a brief for an animated video

Give an animation enough direction to become a coherent short. A beginner, buyer, and child need different examples and language.

A useful short starts with a clear purpose. These steps will help you shape an idea for your audience and review it before sharing.

Name the audience

A beginner, buyer, and child need different examples and language.

State one outcome

Complete: “After watching, the viewer should understand, feel, or do…”

Describe what must be shown

Name subject, setting, action, comparison, and important labels.

Add the story shape

Use question → relationship → takeaway for explainers, or goal → obstacle → change for stories.

Set constraints

Choose duration, aspect ratio, language, voice, and facts to verify.
